# Security Policy

## Reporting a Vulnerability

Please report suspected security issues in Tedious privately using
[GitHub's private vulnerability reporting](https://github.com/tediousjs/tedious/security/advisories/new).
You can also open the repository's **Security** tab, select **Advisories**, and
click **Report a vulnerability**.

Do not disclose vulnerabilities in public issues, discussions, or pull requests.
Reports submitted through this process are private and are not automatically
published as security advisories.

Include the following details where possible:

- A description of the vulnerability and its potential impact.
- The affected Tedious version and relevant environment details.
- Steps to reproduce the issue or a minimal proof of concept.
- Any suggested fix or workaround.

Do not include credentials, secrets, or sensitive customer data in your report.
Use the private report to discuss the issue with the maintainers and coordinate
any public disclosure.
